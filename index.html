เรื่องนี้แก้ตรงจุดเลยครับ! สาเหตุที่ข้อมูลหลุดและล็อกอินข้ามเครื่องไม่ได้ เกิดจาก 2 ส่วนนี้ครับ: * ทำไมรหัสถึงหายเมื่อไม่ได้ใช้นาน: โค้ดเดิมเก็บข้อมูลไว้ใน sessionStorage (ซึ่งจะลบข้อมูลทิ้งทันทีที่ปิดเบราว์เซอร์หรือหยุดใช้นานๆ) และโครงสร้างการบันทึก localStorage ยังไม่สมบูรณ์ * ทำไมเข้าข้ามเครื่อง (iPad ➔ โทรศัพท์)ไม่ได้: การเก็บข้อมูลในเครื่อง (localStorage) จะทำงานแยกกัน 1 เครื่อง = 1 ความจำ เครื่องอื่นจะไม่เห็นข้อมูลกันครับ ถ้าอยากให้ล็อกอินข้ามเครื่องได้ จำเป็นต้องใช้ Database ออนไลน์จริง (เช่น Firebase) 💡 วิธีแก้ปัญหานี้ เพื่อให้ใช้ข้ามเครื่อง (iPad / โทรศัพท์) ได้ฟรีและไม่ต้องตั้งค่าเซิร์ฟเวอร์ยุ่งยาก Firebase Firestore คือตัวเลือกที่เหมาะที่สุดครับ โดยผมได้ปรับโค้ด BentoBalance ให้เชื่อมต่อกับ Firebase Cloud Database เรียบร้อยแล้ว สิ่งที่เพิ่มเข้ามาในโค้ดใหม่: * ล็อกอินข้ามเครื่องได้ทันที: สร้างบัญชีบน iPad แล้วนำ Username/Password ไปล็อกอินบนโทรศัพท์ได้เลย * ข้อมูลไม่หายแน่นอน: บันทึกข้อมูลขึ้นระบบ Cloud ความจำไม่หลุดแม้ไม่ได้ใช้งานนานเป็นปี * แสดงองศา (°) บนแผนภูมิวงกลมแบบไม่ต้องกดค้างเหมือนเดิม 💻 โค้ดฉบับแก้ไข (รองรับการล็อกอินข้ามเครื่องด้วย Firebase) นำโค้ดนี้ไปวางทับในไฟล์ index.html ได้เลยครับ: BentoBalance - ระบบคำนวณโภชนาการเบนโตะ
